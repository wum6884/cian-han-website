# CIAN HAN Modern Website

Static, deployment-ready B2B company website for CIAN HAN Co., Ltd.

## Deploy
Upload this folder to any static host (Cloudflare Pages, GitHub Pages, Netlify, etc.). No server/database is required for the launch version.

## Domain
Point `cianhan.com.tw` DNS to the chosen host. Keep DNS/SSL at Cloudflare if desired.

## Content
This first launch version uses confirmed CIAN HAN positioning and the existing SA-10S/product categories. Product-detail pages and downloadable PDFs can be added as the next content layer without changing the visual system.
